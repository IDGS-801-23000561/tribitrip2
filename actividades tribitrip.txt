EPIC F01 — Autenticación y gestión de usuarios
Descripción del Epic: Desarrollar los mecanismos de acceso al CRM, administración de cuentas y control de permisos para los roles de administrador y asesor de viajes.
Issue HU-001 — Iniciar sesión en el sistema
Alta

Semana 2

Descripción: Como usuario autorizado, quiero iniciar sesión mediante correo electrónico y contraseña para acceder de forma segura a las funcionalidades correspondientes a mi rol.

Criterios de aceptación: El sistema valida las credenciales, permite el acceso a usuarios activos, rechaza credenciales incorrectas, protege las rutas privadas y permite cerrar sesión.

Tasks:
- T01. Diseñar la tabla de usuarios y los campos de autenticación.
- T02. Implementar el almacenamiento seguro de contraseñas.
- T03. Desarrollar el endpoint de inicio de sesión.
- T04. Implementar validación de tokens y protección de rutas.
- T05. Crear la interfaz de inicio de sesión.
- T06. Integrar el formulario con la API.
- T07. Implementar cierre de sesión y manejo de errores.
- T08. Ejecutar pruebas de autenticación.

- T06. Validar permisos desde frontend y backend.
- T07. Realizar pruebas de autorización.
